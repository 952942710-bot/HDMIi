测试说明

什么是HDTI？

HDTI（Historical Dynasty Type Indicator）千古帝王人格测试，是一款对标MBTI/SBTI的国风帝王主题人格测试，以中国历代帝王为原型，通过奏折体策问题目测算用户专属帝王人格类型。

测试原理

HDTI严格遵循MBTI 4维度独立计分逻辑，单题仅对应单一维度，无跨维度计分。4个维度为：

  • E/I（精力来源）：外向/内向
  • S/N（认知方式）：感觉/直觉
  • T/F（决策依据）：思考/情感
  • J/P（行事模式）：判断/知觉

计分规则

所有题目为5级梯度选项，对应单一维度两极偏好，权重固定：

  • 御批A（+2分 / 正极）
  • 御批B（+1分 / 正极）
  • 御批C（0分 / 中立）
  • 御批D（-1分 / 负极）
  • 御批E（-2分 / 负极）

维度判定总规则：4维度独立计分、互不干扰；单个维度6道题总分＞0，取维度正极字母；总分≤0，取维度负极字母；4字母组合为最终HDTI类型，对应匹配专属帝王。

测试流程

  1. 进入测试页面，点击「开始批阅策问」按钮
  2. 回答24道策问题目，每道题选择一个选项
  3. 完成所有题目后，系统自动计算并显示测试结果
  4. 查看你的帝王人格类型及解读
  5. 分享你的测试结果给朋友
